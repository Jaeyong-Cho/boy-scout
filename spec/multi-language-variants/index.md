# Multi-language variants

## Business value
Each language gets its own unambiguous tool/skill name instead of colliding on plain 'gardener'.

## Completion criteria
Every Story below shipped.

## Overview
This EPIC starts with renaming the existing Go tool from `gardener` to `gardener-go`, establishing a per-language naming scheme. Future Stories will add other language-specific tool variants (Python, JavaScript, etc.) as implementation demand arises; those are out of scope for this EPIC.
